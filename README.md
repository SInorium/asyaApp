# Ася · картины

Личный магазин-каталог для продажи картин. Посетители смотрят каталог и оставляют заявку на понравившуюся работу, автор управляет картинами и заявками в закрытой админ-панели.

Сейчас сайт ведёт один владелец, но данные уже рассчитаны на нескольких авторов и другие арт-товары. Онлайн-оплата и корзина запланированы на потом.

## Возможности

**Для посетителей**
- каталог на главной странице с фильтрами по наличию, виду работы и цене (фильтры хранятся в адресе, ими можно делиться);
- страница картины с галереей, описанием, размерами и ценой;
- заявка на покупку (имя, почта, телефон, комментарий) с защитой от спама.

**Для автора** (`/admin/`)
- вход и регистрация автора (регистрация пока только по коду приглашения);
- добавление и редактирование картин: название, описание, цена, размеры, техника, год;
- загрузка фотографий перетаскиванием, выбор обложки, порядок, удаление;
- статусы картин: черновик, в продаже, забронирована, продана;
- список заявок с отметками «новая / в работе / закрыта».

## Технологии

| Часть | Что используется |
|---|---|
| Репозиторий | pnpm workspaces, Turborepo |
| `apps/web` — публичный сайт | Next.js 16 (App Router, Cache Components), Tailwind CSS 4 |
| `apps/admin` — админ-панель | Vite, React 19, TanStack Router / Query / Form, Tailwind CSS 4 |
| `apps/api` — сервер | NestJS 11, Prisma 7, PostgreSQL, JWT в httpOnly cookies |
| Файлы | S3-совместимое хранилище (RustFS в разработке) |
| Общий код | `packages/shared` (zod-схемы), `packages/ui` (компоненты), `packages/api-client` (клиент API, генерируется из OpenAPI) |
| Архитектура фронтенда | Feature-Sliced Design, проверяется `steiger` |

## Быстрый старт

Нужны: Node.js, pnpm 12 и Docker.

```bash
pnpm install
docker compose up -d postgres s3 caddy

cp .env.example .env
cp .env apps/api/.env
cp .env apps/web/.env

pnpm --filter @asya/api db:generate   # клиент Prisma
pnpm db:migrate                       # миграции
pnpm db:seed                          # владелец и демо-картины
pnpm dev                              # api, web и admin
```

Открывайте через единый адрес `http://localhost:8080`:

| Адрес | Что там |
|---|---|
| `http://localhost:8080/` | публичный сайт |
| `http://localhost:8080/admin/` | админ-панель |
| `http://localhost:8080/api/docs` | документация API (Swagger) |

Демо-вход после seed: `owner@asya.local` / `owner12345`. Для любого общего или боевого окружения смените значения в `.env`.

## Команды

| Команда | Что делает |
|---|---|
| `pnpm dev` | запускает все приложения (api :4000, web :3000, admin :5173) |
| `pnpm build` | собирает всё |
| `pnpm typecheck` | проверка типов во всех пакетах |
| `pnpm lint` | проверка архитектуры FSD (steiger) |
| `pnpm api:generate` | пересоздаёт клиент API после изменений на сервере |
| `pnpm db:migrate` / `pnpm db:seed` | миграции и начальные данные |
| `pnpm --filter @asya/web dev` | запуск одного приложения (также `@asya/admin`, `@asya/api`) |

Автотестов пока нет: Jest и Vitest подключены, но тесты не написаны.

## Структура

```
apps/
  api/      NestJS: авторизация, картины, загрузки, заявки
  web/      Next.js: публичный каталог
  admin/    Vite SPA: кабинет автора
packages/
  shared/      zod-схемы и перечисления, общие для сервера и фронтендов
  ui/          набор компонентов и дизайн-токены
  api-client/  клиент API, сгенерированный из OpenAPI
  config/      общие настройки TypeScript
docs/          инструкции
```
